Backend API – A2SV_HUB

This project is the backend implementation for A2SV HUB, built with Go (Golang), Gin Web Framework, and PostgreSQL. It follows Clean Architecture principles to ensure scalability, maintainability, and separation of concerns.

🚀 Features

User Authentication (JWT-based login & registration)

Role-based Access Control (Admin, User, etc.)

Contest Management (creation, participation, standings)

Rating & Upsolving Logic for contest participants

Optimized PostgreSQL queries with indexing & performance tuning

RESTful API endpoints documented with Swagger

Unit & Integration tests for core modules

🛠️ Tech Stack

Language: Go (Golang)

Framework: Gin

Database: PostgreSQL

Architecture: Clean Architecture

Tools: Docker, Swagger, GitHub Actions (CI), Postman/Insomnia
